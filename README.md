# Airbox Services Site

This is the beginning of a personal services website project for Jonathan Caldwell (a.k.a. Airbox Services).

## About This Project

The purpose of this site is to:
- Present a wide range of services offered: tech support, handyman tasks, cleanup, tutoring, light automotive work, consulting, and more
- Showcase Jonathan’s journey overcoming adversity and rebuilding a sustainable life after disability
- Serve as a central point for supporters to leave encouragement or thanks (Support Wall)
- Provide a reference point for social workers, caseworkers, or community contacts
- Allow referrals, reviews, and proof of recent work to be easily shared

## Roadmap

This project will be built out in phases:
1. Basic info site with markdown content and contact form
2. Integration with GitHub for version tracking
3. Showcase portfolio, volunteer efforts, and community engagement
4. Enable service request submissions and testimonials
5. (Future) Add creative interactive or animated elements to help the site stand out
